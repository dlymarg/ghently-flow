# Ghent Crowd Safety Command Center: Intelligent Urban Monitoring & AI-Driven Triage



An end-to-end, open-source crowd monitoring and safety dispatch system. Originally developed as an enterprise application within Palantir Foundry and AIP, this repository provides a fully decoupled, open-source implementation using Python, DuckDB/Pandas, SQLAlchemy, Google Gemini, and Streamlit.

The system models pedestrian corridors using macroscopic fluid continuity principles ($Q_{\text{net}} = \text{Inflow} - \text{Outflow}$ and $\frac{dQ}{dt}$) to detect crowd crush risks and automatically trigger AI-generated tactical evacuation directives.

---

## Background

* **Urban Congestion Challenges:** High-density public gatherings produce non-linear pedestrian compression risks that can rapidly escalate into crowd disasters without early detection.


* **Real-World Motivations:** Inspired by the need for automated crowd safety during major urban gatherings and past tragedies, including the [Itaewon (Seoul) Halloween crowd surge](https://en.wikipedia.org/wiki/Seoul_Halloween_crowd_crush), the Boston Marathon incident, and championship victory celebrations.


* **Data Foundation:** Built on [open pedestrian measurement telemetry](https://data.stad.gent/explore/assets/druktemeting-gent-kortenmarkt-2022-februari-maart/) recorded outside [Saint Nicholas' Church (Sint-Niklaaskerk) in Ghent, Belgium](https://en.wikipedia.org/wiki/Saint_Nicholas_Church,_Ghent), sourced from the City of Ghent Open Data Portal (`druktemeting-gent-kortenmarkt-2022-februari-maart.csv`).



---

## Project Objectives

* **Near-Real-Time Decision-Making:** Enable municipal command center dispatchers to monitor pedestrian flux and identify emerging bottlenecks before physical crush conditions develop.


* **Automated Critical Threshold Detection:** Evaluate continuous macroscopic fluid dynamics to flag abnormal net accumulation ($Q_{\text{net}} > 40\text{ ped/min}$) and rapid fluid compression acceleration ($\frac{dQ}{dt} > 10\text{ ped/min}^2$).


* **AI-Powered Triage Directives:** Ground large language model reasoning strictly in physical sensor calculations to formulate actionable crowd dispersal and rerouting instructions.


* **Synchronized Geospatial & Metric Alerting:** Maintain dynamic synchronization between map markers, live risk statuses, historical time-series telemetry, and active alerts.

## System Architecture & Open-Source Mapping

This project maps the proprietary Palantir Foundry and AIP architecture into an open-source, modular Python stack:

| Palantir Foundry / AIP Component

 | Open-Source Implementation | Core Responsibilities |
| --- | --- | --- |
| **Pipeline Builder**<br> | `src/etl.py` (Pandas / SQLite) | Ingests raw telemetry, parses coordinates across formats (WKT / `geo_point_2d`), unpivots wide columns (43 streams down to directional pedestrian flux), aggregates inflow/outflow per node, and generates primary keys.

 |
| **Ontology Manager**<br> | `src/models.py` (SQLAlchemy ORM) | Creates a semantic digital twin by modeling physical `SensorNode` objects and `CrowdChokepoint` telemetry logs with dynamic 1-to-many relationships and compound indexing.

 |
| **Code Repository**<br> | `src/physics.py` (Python Fluid Engine) | Computes macroscopic mass conservation, calculates time-normalized compression acceleration ($\frac{dQ}{dt}$), and applies operational staleness guardrails.

 |
| **AIP Logic**<br> | `src/agent.py` (Google Gemini GenAI SDK) | Employs `gemini-3.6-flash` with automated function calling to execute deterministic physics checks and draft structured incident-command directives.

 |
| **Workshop Module**<br> | `app.py` (Streamlit + Folium + Plotly) | Delivers an interactive operations dashboard featuring geospatial digital-twin mapping, dynamic KPI cards with inverted accumulation deltas, and time-series telemetry charts.

 |

## How to Execute the Application

### 1. Prerequisites & Environment Setup

Clone the repository and create a Python virtual environment (Python 3.9+ recommended):

```bash
git clone https://github.com/your-username/ghently-flow.git
cd ghently-flow

python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

```

### 2. Install Dependencies

Install the required packages from `requirements.txt`:

```bash
pip install -r requirements.txt

```

### 3. Configure API Credentials

The autonomous AI triage dispatcher requires access to the Google Gemini API. Export your key as an environment variable:

```bash
# macOS / Linux
export GEMINI_API_KEY="your-gemini-api-key"

# Windows (Command Prompt)
set GEMINI_API_KEY=your-gemini-api-key

# Windows (PowerShell)
$env:GEMINI_API_KEY="your-gemini-api-key"

```

*(Alternatively, add `GEMINI_API_KEY = "your-api-key"` to `.streamlit/secrets.toml`).*

### 4. Run the ETL Pipeline

Transform the raw telemetry and build the indexed SQLite database (`data/ghent_telemetry.db`):

```bash
python src/etl.py

```

### 5. Launch the Command Center Dashboard

Start the Streamlit web application:

```bash
streamlit run app.py

```

Open your browser to `http://localhost:8501` to view the command center, inspect live camera nodes, and generate automated AI tactical directives.

## Outcomes & Operational Impact

* **Continuum Fluid Monitoring:** Replaces static thresholding with dynamic fluid accumulation ($Q_{\text{net}}$) and compression acceleration ($\frac{dQ}{dt}$).


* **Automated Triage Escalation:** Categorizes node status into `NOMINAL`, `ELEVATED`, or `CRITICAL` based on empirical crowd flow rates.


* **Actionable Ground Directives:** Dispatches clear, structured routing commands to redirect foot traffic toward open spaces (such as the Korenmarkt square) before chokepoints experience crush pressures.


* **Decoupled Architecture:** Runs locally or inside containerized cloud instances without proprietary vendor lock-in.
